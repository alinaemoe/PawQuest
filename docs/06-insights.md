# 06. Insights (экраны). Формулы — в `09-analytics-algorithms.md`

## 6.1 Принципы отображения
1. Любое число рядом с выводом сопровождается **n** и **периодом**.
2. Доли показываем с интервалом: «3 из 7 (43%, диапазон 16–75%)».
3. Пороги достоверности (единые, A-00): n < 5 — «мало данных» (вывод скрыт); 5–9 — «предварительно»; ≥ 10 — без пометки.
4. Формулировки: «совпадает чаще», «различие заметно/возможно/неясно». Запрещены «из-за», «вызывает», «причина».
5. Любая карточка имеет кнопку **«Показать записи»** (раскрывает исходные события).
6. Нейтральные цвета: один акцент для «текущего периода», приглушённый для «прошлого»; красный/зелёный не используются для оценок поведения.
7. Все графики доступны как таблица (переключатель «График / Таблица») и экспортируются.

## 6.2 Экран Insights (S13)

Верх: **панель периода** — чипы `7 дн · 14 дн · 30 дн · 90 дн · Всё · Свой`; переключатель «Сравнить с предыдущим периодом» (по умолчанию ВКЛ); фильтры-чипы (см. §6.5). Ниже вкладки: **Обзор · Навыки · Поведение · Места**.

### Вкладка «Обзор» (S13-O)
| ID | Блок | Содержимое | Поведение |
|---|---|---|---|
| S13-O1 | Активность | Прогулки, время, расстояние за период; дельта к предыдущему | Тап → график по дням (столбики), переключатель метрики. |
| S13-O2 | Ритм дня | Гистограмма «в какое время гуляем» (24 ч), медианное время первой/последней прогулки | |
| S13-O3 | Дни недели | 7 столбиков: прогулок и минут | |
| S13-O4 | **Дистанция реакции** (Threshold tracker) | Линия медианной дистанции реакции по неделям + точки событий; подпись «Реакция начиналась с ~8 м → ~5 м за 6 недель (n=22)» | Выбор триггера (Собака / Человек / Все). Тренд только при ≥ 6 недельных точек или ≥ 8 событиях, иначе «мало данных». |
| S13-O5 | **Время восстановления** | Медиана и разброс (ящик) по неделям, логарифмическая шкала | Только события с ненулевым `recovery_s`; показывает долю «не знаю». |
| S13-O6 | Нагрузка дня | Календарь-тепловая карта (нейтральный оттенок) | Тап по дню → лента дня. |
| S13-O7 | Карточки закономерностей | До 5 pattern cards (см. §6.4) + «Ещё N» | |
| S13-O8 | Недельный итог | Текстовый, из шаблонов (см. A-17) | Кнопка «Поделиться картинкой». |

### Вкладка «Здоровье и активность» (S13-H)
- **Вес и активность:** вес и недельное время в движении на одной оси времени (A-27); переключатель второго ряда: лакомства (≈ ккал), тренировки, реакции.
- **Выводы текстом:** описательные сравнения периодов без рекомендаций.
- **Зоны скорости за период:** сколько времени на каждой скорости (суммарно по прогулкам) и динамика «к концу прогулки темп» (A-25).
- **Прогулки: сравнение с обычным:** распределение длительности, медиана, выделение необычных (A-18).
- **Питание:** ≈ ккал лакомств по неделям и по контексту (прогулка/тренировка/дом).

### Вкладка «Проекты» (S13-Pj)
Для каждого активного проекта (например «Фризби»): лестница ступеней, доли ловли по условиям с интервалами, вовлечённость во времени, серия, что совпадает с лучшими сессиями. См. `15-learning-projects-frisbee.md` §15.4.

### Вкладка «Навыки» (S13-S)
- Таблица навыков: практики за период, дней с практикой, медианный интервал между сессиями, доля успеха (с интервалом), тренд, последняя практика.
- «Сравнить условия»: выбор навыка → контексты (дома/двор/парк/улица) → столбики с интервалами + вывод по D-19 («различие заметно / возможно / неясно») с n.
- «Отвлечение»: доля успеха по группам D (1–2 / 3 / 4–5).
- «Давно не практиковали»: список навыков с интервалом > 1,5× от личной нормы.

### Вкладка «Поведение» (S13-B)
- Распределение событий по типам (на час прогулки), топ-5 типов.
- Реакции по уровням R1–R5 (3 группы), по триггерам, по дистанциям (чипы).
- Совпадения (lift): «Сложные моменты чаще при … » — список условий (время суток, погода, место, предыдущий триггер за 30 мин, нагрузка вчера) с лифтом, n и поддержкой.
- «Что совпадает со спокойными прогулками» (прогулки без сложных моментов): те же условия, перевёрнутая логика.
- Самый спокойный отрезок (макс. интервал без «Сложно») и его тренд.

### Вкладка «Места» (S13-P)
- Карта событий (кластеры), тепловая карта триггеров, список мест с долей «сложных моментов на час».
- Сравнение двух мест (аналог сравнения контекстов).

## 6.3 Сравнение периодов (S13-Cmp)
Показывается в «Обзоре» при включённом переключателе и отдельным экраном «Сравнить»: выбор A и B (периоды, прогулки, места, контексты).
Таблица метрик: A, B, разница, n(A), n(B), метка надёжности. Шаблон текста:
> «За последние 14 дней вы записали 8 тренировок подзыва — на 3 больше, чем за предыдущие 14 дней. Положительные оценки в тихих местах встречались чаще, чем на оживлённых (n=8 и n=5; различие возможно, но выборка небольшая).»

## 6.4 Карточки закономерностей (pattern cards)

Структура: заголовок-формулировка; «числа» (A: x/n, B: y/m); визуал (два столбика с интервалами); метка надёжности; кнопки «Показать записи» · «Скрыть» · «Сохранить фильтр».

Генерация (A-14): перебор заранее заданных пар «измерение × исход»:
- измерения: контекст, место, время суток, день недели, погода (температура-диапазон, осадки), отвлечение D, нагрузка вчера, длительность прогулки, предыдущий триггер;
- исходы: успех навыка, «сложный момент на прогулку», реакция ≥ 3, восстановление > медианы.
Фильтры: n в каждой группе ≥ 5, поправка на множественные сравнения (BH, FDR=0.2), размер эффекта ≥ порога. Лучшие по эффекту — максимум 5 в день; всегда подпись «найдено среди N проверенных сравнений».
Карточки можно скрыть на неделю/навсегда; повтор одной и той же закономерности не показывается чаще раза в 7 дней.

## 6.5 Конструктор фильтров (S13-F)
Чипы, комбинируются по И внутри группы «не равно/равно», по ИЛИ внутри значений одного измерения:
- тип события, реакция ≥ N, дистанция, восстановление > X с;
- место/категория места, контекст, навык, ступень;
- погода (температура-диапазон, осадки), время суток, день недели;
- «до/после даты» (например «после начала тренировок»).
«Сохранить как умную папку» — фильтр получает название и значок и доступен в Журнале и Insights.
Любой набор фильтров применяется ко всем вкладкам; справа показывается сколько записей подходит («подходит 37 записей»).

## 6.6 Экспорт отчёта для специалиста (S13-Rep)
Кнопка «Отчёт» → форма: период, разделы (переключатели): Сводка · Дистанция реакции · Время восстановления · Топ-5 типичных ситуаций · Навыки и прогресс · Журнал симптомов · Заметки владельца; язык; «Включить личные заметки?» (по умолчанию нет).
Результат — PDF на 1–3 страницы: шапка (собака, период), краткие числа с n, 2–3 графика, список ситуаций с примерами, подпись «Данные собраны владельцем; не являются диагнозом».
PDF генерируется на устройстве (HTML → PDF через expo-print), сохраняется в Загрузки / отправляется «Поделиться».

## 6.7 Пустые и малые данные
| Данных | Что показываем |
|---|---|
| 0 прогулок | Пустое состояние + «Показать пример на демо-данных» |
| < 3 прогулок | Только простые числа без графиков трендов, подсказка «Нужно ещё несколько прогулок для сравнений» |
| 3–9 прогулок | Графики активности; блоки трендов скрыты; карточки только «предварительно» |
| ≥ 10 прогулок + ≥ 20 событий | Полный набор |

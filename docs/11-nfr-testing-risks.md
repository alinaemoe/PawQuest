# 11. Нефункциональные требования, тесты, риски

## 11.1 NFR (измеримо)

| ID | Требование | Метод проверки |
|---|---|---|
| N-01 | Запись события на Active Walk: от тапа до записи в БД ≤ 300 мс; отклик UI (haptic + счётчик) ≤ 100 мс | Maestro + замер в dev-режиме |
| N-02 | Холодный старт до Today ≤ 2,0 с на среднем Android (ориентир: Snapdragon 6xx, 4 ГБ) при 1000 прогулок в БД | профилирование, Release-сборка |
| N-03 | Replay: 10 000 точек, 60 fps на среднем Android (p95 кадр ≤ 20 мс) | профайлер |
| N-04 | Расход батареи при записи прогулки с включённым экраном-карточкой ≤ 8 %/ч; с погашенным экраном ≤ 5 %/ч (по замеру на устройстве) | ручной замер 3 прогулок |
| N-05 | Потеря данных при убийстве процесса: ≤ последние 5 секунд трека; события и состояние — 0 потерь | тест: kill во время записи |
| N-06 | Любая основная операция работает без сети | автотест с отключённым fetch |
| N-07 | Размер APK ≤ 80 МБ (release, arm64) | CI |
| N-08 | Объём БД: 5 лет данных (≈7 млн точек) — запросы Insights за 90 дней ≤ 500 мс | синтетический бенчмарк |
| N-09 | Доступность: все интерактивные элементы имеют подписи; контраст AA; работа при шрифте 200 % без обрезаний | проверка вручную + линтер |
| N-10 | Языки: 100 % строк в RU и EN; нет захардкоженных строк | CI проверка ключей |
| N-11 | Тёмная и светлая темы без нечитаемых состояний | визуальные снимки |
| N-12 | Ошибки не роняют приложение: Error Boundary на каждом экране + «Сообщить локально» (лог) | тесты |
| N-13 | Миграции БД безопасны: тест для каждой версии на данных предыдущей | CI |
| N-14 | Экспорт → импорт → экспорт даёт идентичный JSON (идемпотентность) | тест |

## 11.2 Стратегия тестирования

| Уровень | Что | Инструменты | Цель покрытия |
|---|---|---|---|
| Unit | GPS-фильтры, haversine, упрощение, Уилсон, перестановочный тест, Тейл–Сен/Манн–Кендалл, lift, DBSCAN, серия/Лапки, форматтеры, плюрали | Vitest | ≥ 90 % `core` и `insights` |
| Property | Инварианты §9.3 | fast-check | все инварианты |
| Data | Миграции, репозитории, каскады, soft-delete, индексы (EXPLAIN) | Vitest + better-sqlite3 | все миграции |
| Component | Кнопки событий, шторка деталей, кликер, карточки инсайтов, пустые состояния | RNTL | ключевые компоненты |
| Scenario/E2E | Онбординг → прогулка (GPX) → события → Summary → Replay → Insights → экспорт | Maestro на эмуляторе | 8 сценариев |
| Device | Фоновый GPS 3 реальные прогулки, блокировка экрана, убийство процесса, режим экономии батареи | вручную по чек-листу | перед каждой фазой 2+ |
| Visual | Скриншоты ключевых экранов в 2 темах × 2 языках | Maestro/Playwright (web) | регресс-набор |

Тестовые данные: `tools/gpx` (записанные реальные треки без личных данных, синтетические с шумом и скачками, с потерей сигнала), `tools/seed`.

## 11.3 Definition of Done (на задачу)
Код + юнит-тесты на логику; строки в i18n (RU/EN); пустое/ошибочное/загрузочное состояния; доступность (подписи, размеры); ручная проверка на эмуляторе; обновлена документация экрана при изменении поведения; нет TODO без ссылки на задачу.

## 11.5 Spikes (Phase 0, каждый 1–2 дня, чёткий критерий)

| Spike | Вопрос | Критерий успеха |
|---|---|---|
| S1 | Фоновый GPS на реальном Android | 3 прогулки по 20+ мин с погашенным экраном: пропуски ≤ 2 по ≤ 30 с, расход ≤ 5 %/ч |
| S2 | MapLibre + OpenFreeMap в dev build | Маршрут из 1500 вершин и 30 маркеров, жесты без лагов, тёмный стиль |
| S3 | Replay на 10k точек | 60 fps на устройстве, интерполяция по времени работает |
| S4 | expo-sqlite + Drizzle + миграции | Миграция 0001→0002, 1M точек, запрос по `(walk_id, ts)` < 50 мс |
| S5 | Уведомление с кнопками действий | Тап по кнопке записывает событие при заблокированном экране |
| S6 | Proximity/блокировка ввода | Тапы в кармане игнорируются; экран не залипает |
| S7 | Виджет «Быстрые метки» (`18-widgets.md`) | Запись из виджета при закрытом приложении, ≤ 300 мс до подтверждения, переживает перезагрузку |

# 12. Дорожная карта

Темп: 10–15 ч/нед (D-21). Сроки — с запасом ×2 относительно «идеального» плана. Каждая фаза заканчивается рабочим приложением (вертикальный срез), а не набором недоделок.

## Phase 0 — Фундамент и spikes (≈ 2 недели)
- Монорепо, CI, линтеры, i18n-скелет, дизайн-токены (из выбранной темы прототипа).
- Spikes S1–S6 (§11.5), решения по результатам фиксируются в ADR.
- Схема БД v1 + миграции + репозитории; сидер демо-данных (первая версия).
- GPX-симулятор.
**Выход:** приложение запускается на устройстве, пишет тестовую прогулку из GPX в БД, рисует её на карте; spikes закрыты (успех/запасной план).

## Phase 1 — Core Journal (≈ 3–4 недели)
Профиль собаки + онбординг; Today (без аналитики); ручные прогулки; навыки и шаблоны; тренировочная сессия-«кликер»; события вне прогулки и дневник ABC; редактирование/удаление/корзина; пустые состояния; настройки (язык/тема/единицы/модули); демо-режим.
**Дополнено (D-57):** после «кликера» идёт **Здоровье-лайт**: планы профилактики (глисты, клещи, прививка, осмотр), визиты к ветеринару, мягкая карточка на Today, локальные напоминания (`17-health-care.md`).
**Выход:** можно вести дневник без GPS целую неделю; все формы в RU/EN, 2 темы.

## Phase 2 — Real Walks (≈ 3–4 недели)
Pre-walk шторка; Active Walk с GPS, паузой, событиями, таймером восстановления; восстановление после падения; Summary; Walk Details; карта; фото; погода; места (ручные); разрешения и фоновая запись; (опц.) уведомление с кнопками.
**Выход:** 5 реальных прогулок автора без потерь данных; чек-лист устройства пройден; N-01, N-05 выполнены.

## Phase 3 — Insights & Replay (≈ 3–4 недели)
Walk Replay и сравнение; История (список/календарь/карта); Insights (Обзор, Навыки, Поведение, Места); Threshold tracker и время восстановления; pattern cards; конструктор фильтров и умные папки; экспорт JSON/CSV/GPX; PDF-отчёт для специалиста.
**Выход:** Insights на 30 днях реальных данных читаются, метки достоверности работают; N-03, N-08 выполнены; веб-демо опубликовано.

## Phase 4 — PawQuest Experience (≈ 3 недели)
Цели, Лапки, серия, достижения, недельные итоги; здоровье (симптомы, вес, процедуры, напоминания); оффлайн-карты; автобэкап; пользовательские метки и редактор; share-картинки Replay; полировка анимаций и доступности; статистика «что я использую»; чекпоинт D-03.
**Выход:** 4 недели dogfooding завершены, решение по фокусу принято, список правок собран.

# PawQuest — Техническое задание v1.0 (базовая версия)

> Understand your dog. One walk at a time.

Статус: **базовая версия для старта Phase 0**; дальнейшие изменения через журнал решений (`02-decisions.md`, D-xx) и ADR. Дата: 2026-10-14.

**Что изменилось после v1.0 (Phase 1):** учёт здоровья с планами профилактики и визитами к ветеринару (`17-health-care.md`, D-57), виджеты и быстрые входы (`18-widgets.md`, D-58).

**Что изменилось в v1.0:** у прогулки больше нет типа, тренировки запускаются кнопкой прямо на прогулке (D-40); порода исправлена на цвергшнауцера (D-41); диск 18 см Bulldog (D-42); справочник лакомств дополнен (D-43); решение по стеку: React Native на Expo без Expo Go, план Б для GPS (D-44).

**Что изменилось в v0.3:** отметки событий на карте итога и «спокойный отрезок»; Replay со скоростью, зонами скорости, сравнением с обычным и фото (D-33, D-35); проекты обучения и «Фризби» (D-36); ≈ 75 достижений (D-37); вес, питание и вкусняшки с приблизительными ккал (D-38); каталог данных (D-32); устройство разработки Samsung S23 / Android 15 (D-39). Новые файлы: `13-data-catalog.md`, `14-achievements.md`, `15-learning-projects-frisbee.md`, `16-nutrition-weight.md`.

**Что изменилось в v0.2:** библиотека мест с нормализацией названий (D-27), кнопка «Ребёнок» и сетка 3×3 (D-28), палитры в настройках приложения (D-29), история по умолчанию списком (D-30). Новые экраны в прототипе: Библиотека мест (S14) и Настройки (S19).
Цель документа — зафиксировать, *что* строим, до первой строки кода. Любой пункт можно оспорить по его ID (например `S03-B2`, `D-07`, `A-06`).

## Как читать и давать правки

1. Открой HTML-прототип (`prototype/index.html`, он же опубликован как артефакт) — он показывает главные экраны вживую.
2. Читай файлы по порядку (ниже). Каждый экран и кнопка имеют ID.
3. Правки пиши в чат в формате: `S03-B2: сделать крупнее / убрать / поменять поведение`. Можно списком.
4. Раздел `02-decisions.md` — единый журнал решений. Если решение не нравится, правится там.

## Ключевые решения в двух строках

- **Что строим:** offline-first мобильное приложение (Expo / React Native + TypeScript) для дневника прогулок, тренировок и поведения одной собаки (с моделью данных под несколько).
- **Чем отличается:** быстрая отметка событий одним касанием, таймер восстановления, трекер «дистанции реакции», честная статистика с размером выборки, Walk Replay.
- **Чего нет:** AI, бэкенд, аккаунты, синхронизация, соцсеть, публичные рейтинги, диагнозы.

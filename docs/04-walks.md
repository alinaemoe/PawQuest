# 04. Прогулки: Pre-walk → Active Walk → Summary → Details → Replay → История

## 4.1 Машина состояний прогулки

```
idle ──start──▶ active ──pause──▶ paused ──resume──▶ active
                   │                  │
                   └──finish(hold)────┴──▶ finishing ──save──▶ completed
                   └──discard─────────────▶ discarded
   (падение/убийство процесса в active|paused) ──▶ при запуске: recoverable
```

- Состояние и каждая GPS-точка пишутся в SQLite сразу (WAL), чтобы при падении ничего не терялось.
- `recoverable` — прогулка со статусом `active/paused`, найденная при старте. Предлагаем: **Продолжить** (пропущенное время помечается пробелом на треке), **Завершить** (по последней точке), **Удалить**.
- Автозавершение-напоминание: если прогулка идёт > 3 ч, локальное уведомление «Прогулка всё ещё идёт?» с действиями «Завершить»/«Продолжить».

## 4.2 Pre-walk шторка (S02)

Открывается тапом по «Начать прогулку». Должна запускаться вторым тапом без каких-либо других действий.

| ID | Элемент | Поведение |
|---|---|---|
| S02-D | (только при ≥2 собак) чипы собак, мультивыбор | При одной собаке блока нет (G-09). |
| S02-G | ~~Цель прогулки~~ **убрана (D-40)** | Прогулка не делится на «обычную» и «тренировочную»: это просто прогулка, внутри которой может произойти что угодно, в том числе несколько тренировок подряд (S03-T). «Новое место» и «спокойный день» определяются автоматически по данным. На старте остаются только место и GPS. |
| S02-L | **Блок «Где гуляем?»** — библиотека мест (подробно в §4.2а и S14) | Авто-предложение по геопозиции («Парк у дома?» → «Да»), чипы недавних/частых мест, плитки типов места (Парк · Луг · Двор · Район · Лес · Набережная · Площадка · Ещё), кнопка «+ Новое место». Выбрать можно и только тип («Луг») без названия: прогулка получает тип места, а назвать и сохранить его можно позже в Summary. |
| S02-I | Инфо-строка: погода сейчас, световой день, последние сложные места поблизости («2 сложных момента здесь за 30 дней») | Только факты и ссылки на записи; не «рекомендации». |
| S02-M | Переключатель «Записывать маршрут (GPS)» | По умолчанию ВКЛ. Выкл. → режим «без GPS» (таймер + события, расстояние по шагомеру если доступен). |
| S02-B | **Кнопка «Начать»** (крупная) | Старт: проверка разрешений → запуск сервиса → переход на Active Walk. |
| S02-C | «Отмена» (свайп вниз) | Закрывает шторку без изменений. |

Проверка разрешений при старте (S02-B):
- Разрешено «всегда/в фоне» → ок.
- Разрешено «только при использовании» → старт с предупреждением на Active Walk (плашка: «Держите экран включённым или разрешите фоновую запись») и кнопка «Не гасить экран».
- Отказано → шторка с объяснением и кнопками «Открыть настройки» / «Записать без GPS».
- Android: если включена оптимизация батареи для приложения — показывается разовый совет по исключению (вариации для Honor/Xiaomi/Samsung в справке).

## 4.2а Выбор места: библиотека вместо свободного текста (S02-L)

Проблема: если место вводится руками, получаются «парк», «Парк у дома», «парк дома», «парк 2» — как один и тот же парк в статистике не посчитать. Решение: место всегда имеет **тип из справочника** и (необязательно) **название**, а введённый текст приводится к понятному виду.

**Справочник типов места (иконка + цвет):** Парк/сквер · Луг/поле · Двор · Район/квартал · Лес/роща · Набережная/водоём · Площадка для собак · Тихая улица · Оживлённая улица · Ветклиника · Другое. Район может быть «родителем» места (Район → Парк у дома), необязательно.

**Сценарии выбора (каждый — 1–2 тапа):**
1. **Авто-предложение:** по геопозиции и радиусу сохранённых мест («Парк у дома?» → «Да»).
2. **Чип недавнего места:** показываются 4 самых частых/недавних места (сортировка по частоте, затем по давности).
3. **Только тип:** тап по плитке «Луг» → место «Луг» (без названия, без сохранения в библиотеку). После прогулки Summary предлагает «Назвать это место?».
4. **Новое место (шторка):** выбор типа плиткой → поле названия с подсказками-квалификаторами **«у дома · за школой · у реки · новое»** (чипы добавляют уточнение к названию типа: «Луг у дома»). Название необязательно: по умолчанию «{Тип}» или «{Тип} 2», если такое уже есть.

**Нормализация введённого текста (алгоритм A-24, `09-analytics-algorithms.md`):**
- Очистка: пробелы, регистр («парк   у дома!!» → «Парк у дома»), эмодзи и лишняя пунктуация убираются.
- **Распознавание типа по словам:** «сквер/парк», «луг/поле/пустырь», «двор/дворик», «район/мкр/квартал», «лес/роща», «набережная/пруд/озеро/пляж», «площадка», «улица/проспект/бульвар», «вет/клиника». Если слово найдено, тип выбирается сам, и пользователь видит «Распознано: Луг» с возможностью поправить.
- **Поиск дубликатов:** сравнение с библиотекой (триграммы + расстояние Левенштейна + расстояние по координатам для того же типа). При сходстве показывается «Похоже на «Парк у дома». Это то же место?» → **Да, то же** (в библиотеке запоминается синоним, и в будущем такой ввод сам превращается в «Парк у дома») / **Нет, отдельное**.
- Нераспознаваемый ввод (только цифры/знаки) → название заменяется типом, «Другое» предлагается как тип.
- Слишком длинное название обрезается до 40 символов.

**Наведение порядка (S14):** экран «Библиотека мест» показывает «Похожие места: объединить?» и позволяет слить дубликаты (записи прогулок и событий перепривязываются, старые названия сохраняются как синонимы).

## 4.3 Active Walk (S03) — главный экран продукта

### Компоновка
```
┌──────────────────────────────────┐
│ 00:23:41   1.8 км   ● GPS хороший│  S03-H  статус-строка
│ ┌──────────────────────────────┐ │
│ │  карта (следит за позицией)  │ │  S03-M  можно свернуть
│ └──────────────────────────────┘ │
│ ⏱ Реакция 0:24     [Успокоилась] │  S03-R  показывается только при активном таймере
│ [ ◎ Тренировка ] / [тренировка идёт: навык · ✓ ~ ✗ · Готово] │  S03-T
│ [Собака ][Человек][Ребёнок ]     │
│ [Животное][Успех ][Сложно ]      │  S03-E  сетка быстрых меток 3×3
│ [        + Своя метка       ]    │         (до 9 слотов, по умолчанию 6)
│ [ ⏸ Пауза ]  [ ⏹ Завершить ⟳ ]  │  S03-C  управление
└──────────────────────────────────┘
```

### Элементы и поведение

| ID | Элемент | Поведение (микро-спецификация) |
|---|---|---|
| S03-H | Статус-строка: общее время, дистанция, индикатор GPS | Время идёт каждую секунду, шрифт tabular-nums. Индикатор: ● зелёный «хороший» (accuracy ≤ 15 м), ◐ жёлтый «слабый» (≤ 40 м), ○ серый «нет сигнала» (> 30 с без фикса). Цвет дублируется подписью. Тап → шторка деталей GPS (точность, число точек, расход батареи за прогулку). |
| S03-M | Карта | По умолчанию режим «следовать»; жест панорамы отключает слежение, появляется кнопка «⌖ вернуть». Кнопка «⌄» сворачивает карту (экономия батареи, крупнее кнопки). Запоминается. Маркеры событий цветные с формой по типу. |
| S03-E | **Кнопки событий (сетка 3×3, до 9 слотов; по умолчанию 6: Собака · Человек · Ребёнок · Животное · Успех · Сложно; остальные слоты свободны, «+» для своей метки; «Упражнение» из панели убрано, его заменяет кнопка тренировки S03-T)** | **Тап:** мгновенная запись (время, последняя координата), лёгкая вибрация, на кнопке инкремент счётчика, тост «Собака · Отменить» (5 с). **Повтор** того же типа в течение 1,5 с игнорируется (защита от дребезга). **Долгое нажатие (400 мс):** шторка деталей (S04). **Свайп вверх по кнопке** (опц. жест): цикл по быстрой интенсивности 1–2–3 (в настройках, по умолчанию выключено). Порядок и состав слотов настраиваются. Счётчики видны всегда. |
| S03-T | **Кнопка «Тренировка» (D-40)** — широкая, акцентная, над сеткой событий. Нужна, чтобы тренировка внутри прогулки запускалась в 2 касания и не уводила с экрана прогулки. | **Тап:** шторка «Какой навык?» (недавние первыми, проект «Фризби» помечен, «+ Новый навык»). **Тап по навыку сразу начинает тренировку**, шторка закрывается. |
| S03-Tb | **Панель тренировки** (заменяет кнопку, пока тренировка идёт) | Название навыка (тап по ▾ открывает ту же шторку, чтобы сменить навык: текущая сессия автоматически сохраняется, если в ней были попытки, и начинается новая), таймер и число попыток, **три крупные кнопки результата (≥ 76 dp): ✓ Получилось · ~ Частично · ✗ Не вышло** со счётчиками (для проекта «Фризби»: Поймала · Коснулась · Упустила), «−1 последняя», **«Готово»**. Сетка событий остаётся доступной ниже, и их можно отмечать во время тренировки как обычно. «Готово» сохраняет сессию, привязанную к прогулке (`walk_id`), и возвращает кнопку «Тренировка». Тренировка без попыток не сохраняется. За прогулку можно провести любое число тренировок, в том числе подряд и по разным навыкам. На таймлайне и карте каждая сессия помечена автоматически (фиолетовый квадрат). Контекст (дом/двор/парк/улица) и отвлечение подставляются автоматически из типа места и событий, меняются в итоговой шторке. |
| S03-R | Лента «таймер восстановления» | Запускается: (а) при тапе «Сложно», (б) если в S04 выбрана реакция ≥ 2. Показывает «Реакция 0:24» и кнопку **«Успокоилась»**. Тап на кнопку останавливает таймер и записывает `recovery_s`. Если не нажато за 10 мин или до завершения прогулки → `recovery_s = NULL` (неизвестно, не 0). Несколько реакций подряд: новая реакция закрывает предыдущую с NULL и запускает новый таймер. |
| S03-P | Кнопка «⏸ Пауза / ▶ Продолжить» | Тап. Пауза: останавливает время движения и запись трека (сервис остаётся живым). Плашка «Пауза 00:45». Авто-пауза (опция): при скорости < 0,3 м/с > 90 с предлагается тостом «Пауза? (Да)»; в настройках можно включить автоматическую паузу без вопроса. |
| S03-F | Кнопка «⏹ Завершить» | **Удержание 1 с** с заполняющимся кольцом и вибрацией «предупреждение». Одиночный тап показывает подсказку «Удерживайте, чтобы завершить». Прерывание удержания отменяет. |
| S03-L | Блокировка ввода («карманный режим») | Кнопка «🔒» или авто-блокировка по датчику приближения: тапы игнорируются, экран затемняется (OLED-чёрный), разблокировка — жест «потяни вверх» или нажатие кнопки питания. Включается в Настройки → Прогулка. |
| S03-W | Не гасить экран | Тумблер в шторке деталей GPS; по умолчанию выкл. Если фоновое разрешение не выдано — включается предложением. |
| S03-N | Заметка | Кнопка «✎» в верхней строке: быстрая заметка к текущей прогулке (одна строка, диктовка клавиатурой). Не обязательна. |
| S03-Ph | Фото | Кнопка «📷»: открывает камеру, снимок прикрепляется к ближайшему событию или к прогулке по времени. |
| S03-X | Баннер ошибок | Над кнопками: «GPS потерян 40 с», «Низкий заряд 15% — рекомендуем сохранить» (мягко), «Фоновая запись ограничена». Не блокирует. |

### Уведомление записи (Android, по spike S5)
Постоянное уведомление с таймером и кнопками действий: **Собака · Успех · Сложно · Пауза**. Нажатие записывает событие без открытия приложения. Если spike провален — показывается только таймер + «Открыть».

### События — типы по умолчанию
| key | RU | Вид | Таймер реакции | Цвет/форма маркера |
|---|---|---|---|---|
| `dog` | Собака | trigger | нет (опц. в S04) | оранжевый круг |
| `person` | Человек | trigger | нет | синий круг |
| `child` | Ребёнок | trigger | нет (опц. в S04) | розовый треугольник |
| `animal` | Животное | trigger | нет | зелёный круг |
| `success` | Успех | outcome | — | зелёная звезда |
| `hard` | Сложный момент | outcome | **да** | красный ромб |
| `exercise` | Тренировка (авто) | action | — | фиолетовый квадрат; **создаётся автоматически при старте тренировки (S03-T)**, на панели меток по умолчанию нет |
Дополнительно доступны (в каталоге, не на панели): Велосипед/самокат, Машина/шум, Кошка, Поднятие с земли, Пометка, Туалет, Игра, Заметка, **Лакомство** (`treat`: запись последней позиции из библиотеки лакомств, 1 тап), Тренировки (в том числе «Фризби») запускаются кнопкой S03-T, а не меткой события. Пользователь может создавать свои (иконка + цвет + вид).

## 4.4 Шторка деталей события (S04)

Открывается долгим нажатием на кнопку события, тапом по маркеру/строке таймлайна, или из Summary/Details. Закрытие смахиванием **сохраняет** (кнопки «Сохранить» нет; есть «Удалить событие»).

| ID | Поле | Тип | Заметки |
|---|---|---|---|
| S04-1 | Тип события | чип (меняется) | |
| S04-2 | Дистанция до триггера | чипы **Далеко (>15 м) · Средне (5–15 м) · Близко (<5 м)** + кнопка «Точнее» → ввод метров (шаг 0,5) | Границы настраиваются; метры имеют приоритет над чипом. |
| S04-3 | Реакция | 5 якорных уровней (§4.9) | Выбор ≥ 2 запускает таймер восстановления. |
| S04-4 | Что делал я | мульти-чипы: Увеличила дистанцию · Переключила внимание · Дала команду · Угостила · Развернулись · Ничего | |
| S04-5 | Итог | одиночные чипы: Быстро успокоилась · Потребовалось время · Продолжается · Не знаю | |
| S04-6 | Восстановление (сек) | автозаполняется таймером; вручную можно править | |
| S04-7 | Мысль владельца (интерпретация) | текстовое поле, помечено курсивом, подсказка «Это твоя версия, а не факт» | Отдельно от заметки-факта. |
| S04-8 | Заметка / фото / время | текст, камера, время (можно сдвинуть) | |
| S04-9 | Связь с навыком | выбор навыка (если событие «Упражнение»/«Успех») | Создаёт/привязывает попытку (Training attempt). |
| S04-10 | Удалить событие | текстовая кнопка внизу | G-02 |

Принцип: **ничего не обязательно**; заполненность показывается тонким индикатором («заполнено 3 из 8 полей»), который помогает дополнить позже.

## 4.5 Summary (S05)

Открывается после завершения удержанием. Сохранение **одним тапом**.

| ID | Элемент | Поведение |
|---|---|---|
| S05-T | Заголовок прогулки (авто: «Утро · Парк у дома») | Тап → редактирование. Авто-имя: время суток + место; можно изменить правило в настройках. |
| S05-1 | **Карта маршрута с отметками событий** (цветные маркеры той же формы и цвета, что на Active Walk, на тех местах, где событие произошло) + мини-статы: время, время движения, дистанция, темп, набор высоты (если доступно). Под картой — легенда (чипы типов событий; тап по чипу показывает/скрывает этот тип на карте). | Тап по маркеру → S04 (детали события). Тап по карте → полноэкранный просмотр. Маркеры без координаты (GPS не было) на карте не показываются, но есть в списке. |
| S05-2 | Итоги событий: чипы с счётчиками («Собака ×3, Успех ×2, Сложно ×1»), **«Самый спокойный отрезок: 14 мин»** (A-20) | Тап по чипу → список таких событий. Тап по «спокойному отрезку» подсвечивает его на карте утолщённой линией с подписью «14 мин спокойно». Остаётся в Summary обязательно (D-33). |
| S05-Ph | Фото прогулки: полоса миниатюр (если есть) и кнопка «Открыть альбом» | Тап по миниатюре — просмотр; фото привязаны к месту на карте (маркер-камера). |
| S05-3 | Состояние собаки (5 якорных уровней) | Один ряд чипов с подписями, необязательно. |
| S05-4 | Отвлечение на прогулке (1–5 якорных) | Необязательно. Если событий было много, предзаполняется подсказкой «по событиям: 3». |
| S05-5 | Заметка + фото | Диктовка клавиатурой. |
| S05-6 | **Тренировки на этой прогулке** (список сессий, уже сохранённых кнопкой S03-T): навык, число попыток, % успеха, длительность | Тап по строке открывает сессию. Сессии не нужно сохранять повторно. Если тренировка осталась незавершённой, предлагается «Сохранить» / «Отбросить». |
| S05-7 | **Кнопка «Сохранить»** (крупная, закрепленная внизу) | Сохраняет, показывает вибрацию «успех», +Лапки (если включено), тост «Прогулка сохранена · Отменить» (10 с). |
| S05-8 | «Удалить прогулку» (мелко) | Подтверждение удержанием; G-02. |
| S05-9 | «Позже» (закрыть шторку) | Прогулка сохраняется как `completed` без итогов; в ленте — метка «можно дополнить». |
| S05-W | Погода | Автоматически вставляется снимок погоды (если был онлайн): температура, ощущается, осадки, ветер, качество воздуха; можно скрыть. |

Автопредупреждения: прогулка < 30 с или < 20 м → вопрос «Слишком короткая — удалить?»; GPS-выбросы > 3 → «Исправить маршрут» (S06-F).

## 4.7 Walk Replay (S07) — «вау»-экран

Назначение: пройти прогулку заново по времени с картой и событиями.

| ID | Элемент | Поведение |
|---|---|---|
| S07-M | Карта с полным маршрутом (блеклым) и «пройденной частью» (ярко), маркер собаки/точка двигается по времени | Камера: «следовать» / «общий вид» (кнопка). |
| S07-Sc | **Ползунок времени** с метками событий (цветные тики), штриховка пауз | Тянуть пальцем; тап по тику → прыжок к событию и открытие карточки. |

| S07-St | Нижняя строка: текущая дистанция, темп сейчас, число событий «до этого момента» | |
| S07-Cmp | Режим «Две прогулки»: наложение маршрутов разными цветами, синхронизация по прогрессу (% времени) или по реальному времени от старта; метрики рядом | Выбор второй прогулки — из списка с одинаковым местом первыми. |

## 4.8 История прогулок (S08)

Вкладка «Прогулки». Три вида (переключатель): **Список · Календарь · Карта**. **По умолчанию открывается «Список»**; выбранный вид запоминается, но при первом запуске и после сброса всегда «Список».

| ID | Элемент | Поведение |

### S06-Cmp Сравнение двух прогулок
Таблица: длительность, время движения, дистанция, темп, число событий по типам (на час), медианная дистанция реакции, медианное восстановление, погода, место. Разница показывается нейтральными стрелками. Под таблицей — наложение маршрутов. Внизу подпись: «Две прогулки — это малая выборка (n=2)».

## 4.9 Шкалы оценок (якорные, 5 уровней) — D-11

Каждая шкала имеет собственные подписи; в UI всегда показываем 5 чипов с коротким названием, подробную подпись — по долгому нажатию/в подсказке.

**Реакция на триггер (R):**
1. Заметила (посмотрела/принюхалась)
2. Напряглась, замерла, смотрит неотрывно
3. Подала голос или потянула поводок
4. Устойчивый лай/рывки, трудно отвлечь
5. Не реагирует на меня, не удаётся переключить

**Отвлечение среды (D):**
1. Пусто (никого рядом)
2. Редкие прохожие / тихо
3. Обычная улица
4. Много людей / собак поблизости
5. Очень оживлённо / шум / толпа

**Качество сессии/попытки (Q):**
1. Не получилось
2. С большим трудом
3. Нормально
4. Хорошо
5. Очень уверенно

**Состояние собаки (M) — по ощущениям владельца:**
1. Подавлена/тревожна
2. Напряжена
3. Ровная
4. Бодрая
5. Очень радостная/возбуждена

Группировка для статистики (настраивается): 1–2 «низкий», 3 «средний», 4–5 «высокий». **Для D и R высокий уровень = больше раздражителя/реакции, для Q и M высокий уровень = «лучше»**; в UI оси подписаны, цветовая «хорошо/плохо» кодировка не используется (нейтральная шкала одного цвета).

# 05. Тренировки и дневник поведения

## 5.1 Тренировки: обзор (S09)

Вкладка «Тренировки». Сверху сегменты **Навыки · Сессии · Программы** (Программы — Phase 4).

| ID | Элемент | Поведение |
|---|---|---|
| S09-L | Список навыков (карточка: название, ступень протокола, последняя практика «3 дня назад», мини-спарклайн оценок, статус-метка) | Статус-метки нейтральные: «Новый» · «В работе» · «Закреплён» · «Давно не практиковали». Тап → S10. |
| S09-F | Фильтры/сортировка: По давности · По частоте · А–Я; чип «Архив» | |
| S09-A | Кнопка «Новый навык» | Выбор из шаблонов (§5.2) или «Свой навык» (название — обяз.). |
| S09-Q | Кнопка **«Начать сессию»** (закреплена внизу) | Выбор навыка (последний первым, затем часто используемые) → S11. |
| S09-W | Подсказка недели: «Давно не практиковали: Подзыв (9 дн.)» | Показывается, если ≥1 навык отстаёт от своего медианного интервала в 1,5+ раза (см. A-10). |

## 5.2 Шаблоны навыков (нейтральные, без лечебных рекомендаций)

Для каждого шаблона заранее заполнены: описание, критерий успеха, ступени протокола (3–5), контексты. Пользователь редактирует всё.

| Шаблон | Критерий успеха (по умолчанию) | Оси ступеней |
|---|---|---|
| Подзыв | Подошла в течение 5 секунд после сигнала | дистанция (2→5→10→20 м), отвлечение (D1→D4) |
| Свободный поводок | 10 шагов без натяжения | длительность, отвлечение |
| Выдержка («ждать») | Осталась на месте до разрешения | длительность (3→10→30→60 с), дистанция |
| Контакт глазами | Посмотрела на меня за 3 с | отвлечение, расстояние до триггера |
| Место / коврик | Лежит на месте 1 минуту | длительность, отвлечение |
| Спокойное ожидание | Сидит/лежит спокойно при проходящем триггере | расстояние до триггера |
| Новое упражнение | задаётся пользователем | задаётся |

### Ступени протокола (criteria ladder)
Навык хранит список ступеней `skill_level`: номер, название, параметры (дистанция, длительность, отвлечение 1–5, свободный текст), критерий. Текущая ступень отображается на сессии. Приложение предлагает повысить ступень, когда выполнено правило готовности (A-11); решение всегда у пользователя.

## 5.4а Где начинается тренировка (D-40)

Прогулка не бывает «тренировочной»: это просто прогулка, внутри которой может быть несколько тренировок. Поэтому тренировка начинается из контекста, в котором человек находится:

| Откуда | Как | Привязка |
|---|---|---|
| **Во время прогулки** | Кнопка «Тренировка» на Active Walk (S03-T): 1 тап + 1 тап по навыку. Панель с результатами встроена в экран прогулки, ничего не перекрывает. | `walk_id` = текущая прогулка, место и погода наследуются от прогулки |
| **Без прогулки (дома)** | Плитка «Тренировка дома» на Today, вкладка «Тренировки» → «Начать сессию», карточка навыка | `walk_id = NULL`, контекст `home`. В списках помечается значком «дома» |
| **Задним числом** | «Тренировки → + Сессия» | `walk_id` выбирается вручную |

Свойства:
- Одна прогулка = 0…N сессий (разные навыки, разные ступени). Смена навыка во время прогулки: тап по названию навыка на панели.
- Одна и та же сессия-«кликер» (S11) работает одинаково и дома, и на прогулке; на прогулке она показана компактной панелью, дома — полноэкранно.
- Статистика (S10, S13) разделяет «дома» и «на прогулке» как **контекст**, а не как два разных вида занятий.

## 5.4 Тренировочная сессия — режим «кликер» (S11)

Принцип: **один тап = одна попытка**. Все параметры контекста выбираются до старта.

### Подготовка (шторка перед стартом)
| ID | Поле | Поведение |
|---|---|---|
| S11-P1 | Навык | Предвыбран |
| S11-P2 | Ступень | Предвыбрана текущая (меняется чипом) |
| S11-P3 | Контекст | Чипы: Дома · Двор · Парк · Улица · Другое (запоминается) |
| S11-P4 | Отвлечение (D) | 5 чипов; по умолчанию D из последней сессии |
| S11-P5 | Награда | Чипы: Лакомство · Игрушка · Похвала · Свой вариант (необязательно) |
| S11-P6 | Если сессия идёт на прогулке | Связывается с активной прогулкой автоматически (с координатой старта) |
| S11-P7 | **«Начать»** | → экран сессии |

### Экран сессии
```
┌─────────────────────────────┐
│ Подзыв · ступень 3          │
│ 02:14      Попыток 7        │
│ Успех 4  Частично 2  Нет 1  │   доли и % (57%)
│ ┌─────────────────────────┐ │
│ │      ✓  Получилось      │ │  S11-1  крупная, зелёная форма-галочка
│ └─────────────────────────┘ │
│ ┌──────────┐ ┌────────────┐ │
│ │ ~ Частично│ │ ✗ Не вышло │ │  S11-2, S11-3
│ └──────────┘ └────────────┘ │
│  [↶ −1 (отменить)]  [Стоп]  │
└─────────────────────────────┘
```
| ID | Элемент | Поведение |
|---|---|---|
| S11-1 | ✓ Получилось | Тап → попытка `successful`, вибрация, счётчик, обновление процента. |
| S11-2 | ~ Частично | Попытка `partial`. |
| S11-3 | ✗ Не вышло | Попытка `unsuccessful`. |
| S11-4 | ↶ Отменить последнюю | Удаляет последнюю попытку (G-02, не более 5 шагов назад). |
| S11-5 | Секундомер | Идёт с момента старта; можно ставить на паузу (тап на время). |
| S11-6 | Шторка «Подробности попытки» | Долгое нажатие на кнопку результата → отвлечение этой попытки, расстояние, заметка. Редко нужно. |
| S11-7 | «Стоп» | Сводка: попытки, доли, сравнение с предыдущей сессией этого навыка **в том же контексте** («в прошлый раз 3 из 6»), общая оценка сессии (Q1–Q5, предзаполнена по доле успеха, можно изменить), заметка, «Сохранить». |
| S11-8 | Подсказка перехода на ступень | Если выполнено правило A-11, в сводке карточка «Последние 10 попыток ≥ 80% в 2+ контекстах. Перейти на ступень 4?» с кнопками «Да» / «Пока нет». |
| S11-9 | Возврат/пауза | Приложение может быть свёрнуто; сессия хранится как черновик, при возврате продолжается. |

Правила: одна сессия — один навык; в течение сессии нельзя менять ступень; длительность — по секундомеру; можно задним числом добавить сессию (форма в S09: дата/время, навык, число попыток по результатам).

## 5.5 Дневник поведения (S12) — формат ABC

Расположение: Собака → Дневник; на Today — лента; также фильтр внутри каждой прогулки.

### Лента (S12-L)
Строки: время, тип, короткое резюме («Собака · близко · реакция 3 · успокоилась за 40 с»), метка «можно дополнить» (жёлтая точка), иконка прогулки/места. Группировка по дням; сворачивание дня.
Фильтры (чипы-конструктор): тип события, реакция ≥ N, дистанция, место, период, «есть заметка», «заполнено/не заполнено». Сохранение фильтра как «умной папки». Поиск по тексту.
Кнопка «+»: новое наблюдение вне прогулки.

### Форма наблюдения (S12-F) — ABC
Разделена на три блока и отдельную «интерпретацию» (визуально отличается):

| Блок | Поля |
|---|---|
| **A — Что было до** (Antecedent) | Тип триггера (чипы), контекст/место, дистанция (чипы + метры), отвлечение D, что делали до (например «шли спокойно», «играли») |
| **B — Что сделала собака** (Behavior) | Реакция (R1–R5 + мульти-чипы: смотрела, замерла, лай, тяга, прыжки, поскуливание, убежала в сторону, игнорировала…), длительность, заметка-факт |
| **C — Что было дальше** (Consequence) | Что сделала я (мульти-чипы), итог, восстановление (сек), заметка |
| **Мысль владельца** | Свободное поле: «Мне кажется, потому что…»; метка «интерпретация» |
| **Служебное** | Время (можно сдвинуть), связанная прогулка, место, навык, фото, теги |

Все поля необязательны; индикатор заполненности. Быстрый режим: после метки на прогулке «Дополнить позже» собирает неполные записи в раздел «Нужно дополнить» (с количеством на значке вкладки Дневника).

### Карточка наблюдения (S12-D)
Структурированное резюме (A → B → C), мини-карта точки, связанные записи («5 похожих за 30 дней» → фильтр), кнопки: изменить, дублировать как шаблон, удалить.

### «Похожие случаи»
Алгоритм: по триггеру + контексту + диапазону дистанции ищет предыдущие записи; показывает список и мини-график реакции (R) во времени. Только список и числа, без выводов.

## 5.6 Пользовательские события и поля (Custom Event Builder)
Настройки → Быстрые метки → «Новая метка»: название, иконка (из набора), цвет, вид (trigger/outcome/action/physio/note), опции: запускать таймер восстановления; набор доп. полей для S04 (дистанция, реакция, действия, итог). Перетаскиванием меняется порядок на 9 слотах (сетка 3×3); метки сверх 9 доступны через кнопку «Ещё» на Active Walk (шторка).

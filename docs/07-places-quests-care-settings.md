# 07. Места, цели и награды, здоровье и рутина, профиль, настройки, данные

## 7.1 Места (S14)

Расположение: Собака → Места. Принцип: личная память о местах, не рейтинг и не оценка безопасности.

| ID | Элемент | Поведение |
|---|---|---|
| S14-M | Карта сохранённых мест (иконки по категории), кнопка «⌖», поиск места | Тап по маркеру → карточка места (шторка). |
| S14-L | Список мест (сорт.: ближе всего · чаще всего · давно не были) | |
| S14-A | «Добавить место»: **тип (обяз., плитки)** — Парк · Луг · Двор · Район · Лес · Набережная · Площадка · Тихая улица · Оживлённая улица · Ветклиника · Другое; название (необязательно, по умолчанию = тип; чипы-квалификаторы «у дома / за школой / у реки / новое»), родитель-район (необязательно), радиус (25–200 м, по умолчанию 60), точка (текущая / указать на карте), цвет/иконка, заметка | Введённое название проходит нормализацию и поиск дубликатов (A-24): «Похоже на «Парк у дома». Это то же место?» |
| S14-Lib | **Библиотека мест:** список, сгруппированный по типам (счётчики визитов), поиск; сверху блок «Навести порядок» со списком похожих мест и кнопкой «Объединить» | Слияние перепривязывает прогулки/события, старые названия сохраняются как синонимы (`place_alias`), действие можно отменить 8 секунд. |
| S14-Auto | Автопредложение: «Вы часто останавливаетесь здесь. Назвать место?» | A-12 (кластеризация остановок: ≥3 мин, ≥2 прогулок, радиус 40 м). Предложение показывается в Summary и не чаще раза в день; отказ запоминается. |
| S14-Auto2 | Реализовано: карточка в итоге прогулки не чаще раза в день, третья кнопка «Не предлагать здесь» (запоминается на ячейку ≈ 55 м), после названия место привязывается ко всем прогулкам кластера без места. **Предел текущей версии:** место = точка + радиус, предложение считает «рядом» от центра. Развитие: места с размером и формой, заходы вместо остановок, хронология прогулки (`20-places-and-walk-structure.md`, D-62) | Тип и размер места по умолчанию, вложенность и «покрытые» места |
| S14-D | **Карточка места:** число визитов, последний визит, события по типам (на час), навыки, которые практиковались здесь (доля успеха), средние оценки, заметки, фото; список визитов (ссылки на прогулки) | «Фильтр: показать все записи здесь». |
| S14-S | Подсказка перед прогулкой в Pre-walk шторке (фактическая): «Здесь: 3 визита, 2 сложных момента, 4 успешных подзыва» | Только счётчики, без оценок. |
| S14-Del | Удаление места не удаляет записи (ссылка → NULL) | |

Place Memory на Active Walk: при входе в радиус сохранённого места показывается тихий чип «Парк у дома · 5-й визит» (можно отключить).

## 7.2 Цели, задания, серии, очки, достижения (Quests) — S16

Тумблер «Показывать цели и награды» в Настройках (по умолчанию ВКЛ).

### Лапки (очки)
Начисляются только за ведение дневника и практику, не за дистанцию:
| Действие | Лапки | Лимит |
|---|---|---|
| Прогулка сохранена | +10 | — |
| Итог прогулки заполнен (≥2 поля) | +5 | — |
| Событие записано | +1 | до 20 за прогулку |
| Событие дополнено деталями (ABC ≥3 поля) | +3 | до 5 в день |
| Тренировочная сессия сохранена | +10 | — |
| Попытки в сессии | +1 за 2 попытки | до 10 за сессию |
| Недельная цель выполнена | +30 | — |
| Новое место добавлено | +10 | до 3 в неделю |
Дневной предел: 100 Лапок. Нет очков за: километры, число прогулок в день сверх 3, длительность, скорость.

### Уровни
Накопительные, нейтральные названия: **Щенячий шаг (0) → Следопыт (200) → Наблюдатель (600) → Напарник (1500) → Знаток (3500) → Ветеран троп (7500)**. Уровни не откатываются.

### Серия «Дни с записью»
- День засчитывается, если есть ≥1 из: сохранённая прогулка, тренировка, наблюдение/событие, симптом, «день отдыха».
- **День отдыха:** кнопка «Сегодня отдыхаем» (на Today и в плашке серии) — день считается, без записей.
- **Автоматические «лапы-паузы»:** до 2 в неделю автоматически закрывают пропущенный день, серия не обрывается.
- Если серия всё же прервалась: плашка «Серия началась заново. Лучшая: 14 дн.», без красного, без сообщений о «потере».
- **Тихий день:** если «нагрузка дня» (A-08) за вчера выше 85-го перцентиля личных значений, на Today показывается нейтральная карточка «Вчера было много раздражителей. Можно устроить спокойный день» (скрывается кнопкой). Не блокирует и не штрафует.

### Недельные цели (S16-W)
- Авто-предложение на неделю: на основе медианы последних 4 недель +1 (но не больше потолка по типу), 1–3 цели; пользователь может изменить/добавить.
- Типы целей: тренировки (N сессий), навык в двух условиях, N наблюдений, N прогулок с итогом, новый маршрут/место, «спокойная прогулка».
- Кольцо прогресса на Today; завершение недели — карточка «Итог недели» (S16-Recap): что сделано, Лапки, сравнение с прошлой неделей без оценок.

### Достижения (S16-A)
**Полный каталог (≈ 75 достижений, многоуровневые ◆/◆◆/◆◆◆, «Мастерство», скрытые, проект «Фризби») — в `14-achievements.md`.** В S16 они сгруппированы по разделам (Прогулки · Наблюдения · Тренировки · Фризби · Места · Здоровье · Данные), с вкладкой «Мастерство» и прогрессом до следующего уровня. Достижения за экстремальные условия, расстояние и скорость исключены. Ниже — стартовый минимум:
| Название | Условие |
|---|---|
| Первая прогулка | 1 сохранённая прогулка |
| Наблюдатель | 25 событий записано |
| Исследователь | 5 разных мест |
| Постоянство | 4 недели подряд выполнено ≥1 цели |
| Мастер навыка | 30 практик одного навыка |
| Две среды | навык с ≥5 попытками в двух контекстах |
| Ступенька вверх | первое повышение ступени |
| Спокойный отрезок | 30 мин без «Сложно» на прогулке ≥ 30 мин |
| Ранняя пташка | прогулка до 7:00 (5 раз) |
| Вечерний ритуал | прогулка после 21:00 (5 раз) |
| Дождь не помеха | 5 прогулок при осадках |
| Свежий воздух | 20 прогулок при хорошем качестве воздуха |
| Тихий день | 3 отметки «день отдыха» |
| Летописец | 100 записей |
| Дополнено | 20 событий дополнено до ABC |
| Три дня подряд | серия 3 |
| Неделя | серия 7 |
| Месяц | серия 30 |
| Фотоальбом | 25 фото |
| Возвращение | возобновление после перерыва 14+ дней (формулировка тёплая) |
Каждое достижение — карточка с датой получения и «на что опирается» (ссылка на записи). Уведомления о достижениях — только в приложении, без пушей.

## 7.3 Профиль собаки (S15)

Секции экрана (все поля необязательны, кроме имени):
- **Основное:** имя, фото, дата рождения / возраст (авто-вычисление), пол, размер, порода (необязательно, текст), вес (последний из журнала веса).
- **Особенности:** любимые занятия/игрушки/лакомства (теги), триггеры «со слов владельца» (теги, не влияют на аналитику, но подсказывают метки), что успокаивает.
- **Цели:** выбранные в онбординге + свободные.
- **Режим дня:** типичные время и длительность прогулок (используется только для напоминаний и сравнения «обычно/сегодня»).
- **Навыки:** сокращённый список с переходом в Training.
- **История:** хронология ключевых событий (первый день с тобой, вакцинации, переезды, новые навыки) — отдельный журнал «Важные события» с датами.
- **Действия:** сменить фото, архивировать собаку (скрывает из UI, данные остаются), удалить (подтверждение вводом имени), «Добавить вторую собаку» (включает G-09 многособачий UI).

### Режим нескольких собак (после добавления второй)
Появляется переключатель собаки в шапке (аватар-чип), в Pre-walk шторке — выбор участвующих собак, события привязываются к собаке (по умолчанию ко всем участникам, по долгому нажатию — к одной). Статистика раздельная, общая — по запросу. Сложные сценарии (совместные владельцы, роли) вне v1.0.

## 7.4 Здоровье и рутина (Care) — S17

Модуль нейтральный: записывает, напоминает, готовит данные для ветеринара. **Не интерпретирует.** На всех экранах — подпись «Приложение не ставит диагнозов. При сомнениях обратитесь к ветеринару».

### Напоминания
- Повторяющиеся (раз в N дней/недель/месяцев/лет, по дням недели) и разовые: прогулка, тренировка, обработка от паразитов, вакцинация, груминг, визит к врачу, лекарство (название и время — произвольный текст), своё.
- Создание: название (обяз.), время, повтор, заметка, «умное окно» (напомнить за N дней).
- Уведомления локальные; в уведомлении кнопки «Сделано» / «Отложить» (чипы). Результат пишется в журнал событий.
- Тихие часы (по умолчанию 22:00–07:00).
- Не напоминаем «прогулка пропущена»; только по расписанию, выбранному пользователем.

### Журнал симптомов (S17-S)
| ID | Элемент | Поведение |
|---|---|---|
| S17-S1 | «+ Симптом» | Выбор из списка: рвота · диарея · кашель · чихание · хромота · зуд/расчёсывание · вялость · снижение аппетита · повышенная жажда · потеря шерсти · выделения · другое (текст) |
| S17-S2 | Форма записи | Когда началось (по умолчанию «сейчас», можно изменить), сколько раз/как часто (чипы: один раз · несколько · постоянно), выраженность (3 уровня: слабо · заметно · сильно), что ела/пила (текст), что делали (текст), фото, заметка |
| S17-S3 | Продолжение | Для длящегося симптома кнопка «Всё ещё есть / прошло» → таймлайн отмечает длительность |
| S17-S4 | Таймлайн | Лента симптомов вперемешку с прогулками/тренировками (чтобы видеть контекст), фильтр по симптому |
| S17-S5 | «Вопросы к ветеринару» | Подсказка, что полезно записать (когда началось, частота, аппетит, поведение, лекарства) — статичный чек-лист, не оценка |
| S17-S6 | «Показать ветеринару» | PDF-справка (период, хронология, фото, вес, процедуры) |

### Справка «Срочные признаки» (S17-U)
Статичный перечень ситуаций, при которых не ждут, а звонят в клинику (затруднённое дыхание, бледные/синюшные дёсны, судороги, потеря сознания, сильное кровотечение или тяжёлая травма, подозрение на отравление, безуспешные попытки рвоты со вздутым твёрдым животом, невозможность помочиться, сильная боль). Кнопка «Позвонить в клинику» (контакт задаётся пользователем). Приложение само **никогда не решает**, срочно или нет, — только показывает справочный список.
*Содержимое — заглушка до проверки ветеринаром (R-09).*

### Журнал веса (S17-W) и питание (S20)
Подробная спецификация — в **`16-nutrition-weight.md`**: учёт веса с графиком и сравнением с активностью, питанием, тренировками и поведением; мягкое напоминание «Взвесьте собаку» при устаревших данных (по умолчанию 14 дней); библиотека лакомств и погрызушек (сушёные лёгкое, ухо, трахея, желудок, сырые ухо/нос/трахея и др.) с приблизительными ккал и записью «когда и что давали»; выводы по активности без оценок и рекомендаций. Подпись везде: «Ориентировочные значения. Динамику веса и рацион обсуждайте с ветеринаром».

### Процедуры
Записи типа вакцинация/обработка/визит: дата, название, заметка, следующая дата (создаёт напоминание), документ-фото.

## 7.5 Календарь (S18)
Общая вкладка в Прогулках (вид «Календарь»). Точки: прогулки, тренировки, наблюдения, симптомы, процедуры, напоминания. Тап по дню — лента дня с возможностью добавить запись задним числом. Нет красных пропусков.

## 7.7 «Что я реально использую» (локальная статистика)
Страница только на устройстве: сколько раз за 30 дней открывались модули, сколько записей в каждом, медианное время добавления события, доля сохранённых итогов прогулок. Не отправляется нигде. Нужна для чекпоинта D-03 после 4 недель: помогает решить, какие модули остаются главными.

## 7.8 Экспорт и импорт данных

| Формат | Содержимое | Назначение |
|---|---|---|
| JSON + фото (zip) | Все таблицы, `schemaVersion`, вложения | Полная резервная копия и перенос |
| CSV (по таблицам) | walks, events, sessions, attempts, observations, symptoms, weights | Анализ в Excel/таблицах |
| GPX | Одна/несколько прогулок (трек + путевые точки событий) | Импорт в другие сервисы, тесты |
| PDF | Отчёт для специалиста (§6.6), справка для ветеринара | Печать/отправка |
| Картинка | Маршрут/итог недели | Поделиться |

Импорт JSON: режимы **Слить** (по id, побеждает больший `updated_at`) и **Восстановить** (заменить всё, с предупреждением удержанием). Проверка `schemaVersion` и миграция вперёд. Импорт GPX: создаёт прогулку «импортированная» (для тестов и старых данных).
Автобэкап (Phase 4): раз в неделю сохранять JSON-архив в выбранную пользователем папку.

## 7.9 Демо-режим (S21)
- Включается в онбординге или Настройки → О приложении → «Демо-собака».
- Синтетический набор: собака «Луна», 90 дней данных (~70 прогулок на основе нескольких реальных публичных GPX-образцов или сгенерированных маршрутов, 400 событий, 12 навыков/сессий, наблюдения, симптомы, вес), так, чтобы все инсайты показывали осмысленные закономерности (заложенные в генератор), в том числе малые выборки.
- Все демо-записи помечены `is_demo = 1` и удаляются одной кнопкой; не смешиваются с реальными.
- Веб-демо работает только с демо-данными; Active Walk в веб-демо воспроизводит GPX-файл вместо реального GPS.

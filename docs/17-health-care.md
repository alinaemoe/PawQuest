# 17. Здоровье: профилактика, визиты к ветеринару, напоминания

Расширяет раздел 7.4 («Здоровье и рутина») и `16-nutrition-weight.md`. Принцип прежний: приложение **записывает, напоминает и готовит данные для ветеринара**. Оно не ставит диагнозов, не подбирает препараты и **не считает дозировки** (R-09, D-14): доза и название препарата — текст, который вводит человек по назначению врача или инструкции.

Это блок «Здоровье» на вкладке «Собака» (S17). Модуль выключаемый (G-10).

## 17.1 Что учитываем

| Тип записи | Примеры | Особенности |
|---|---|---|
| **Профилактика от паразитов** | глистогонка; обработка от клещей и блох; комбинированная | свой график и сезон |
| **Вакцинация** | комплексная прививка, бешенство | обычно раз в год |
| **Визит к ветеринару** | плановый осмотр, прививка, контрольный, **визит из-за проблемы** (хромает, рвота, кожа…) | причина обязательна одним тапом |
| **Лекарство (курс)** | название, как давать (текст), сколько дней | Phase 5, пока только напоминание «по тексту» |
| **Груминг и прочее** | стрижка, когти, зубы | необязательно |
| **Вес** | см. `16-nutrition-weight.md` | уже готово |
| **Симптомы** | см. 7.4 (S17-S) | связываются с визитом |

## 17.2 Планы профилактики (рутины)

План — это «что и как часто». Пользователь включает нужные, ничего не включено по умолчанию (G-23: без навязчивости). При первом запуске на Today один раз показывается мягкая карточка «Настроить напоминания о здоровье» (кнопки «Настроить» / «Не сейчас»).

| План (шаблон) | Интервал по умолчанию | Окно напоминания | Комментарий |
|---|---|---|---|
| Глистогонка | каждые 3 месяца | за 7 дней до срока и в день срока | интервал можно менять: 1 / 3 / 6 мес. |
| Клещи и блохи | каждые 30 дней, **в сезон** (апрель–октябрь, меняется) | за 3 дня до срока | вне сезона план «спит»; сезон задаётся месяцами; интервал под используемый препарат (по упаковке) |
| Вакцинация | раз в 12 месяцев | за 30 и за 7 дней | дата следующей берётся из последней прививки |
| Плановый осмотр | раз в 12 месяцев | за 14 дней | «проверка раз в год» |
| Вес | каждые 14 дней | см. `16-nutrition-weight.md` | уже работает |
| Своё | любой интервал, одноразово или повтором | задаёт пользователь | |

Поля плана: название, интервал (дни или месяцы), сезон (необязательно), за сколько дней напоминать, препарат по умолчанию (текст, подставляется при отметке), включён/выключен.

**Как считается срок.** Следующая дата = дата последней выполненной записи + интервал. Если записей ещё нет, пользователь задаёт «когда было в последний раз» (по приблизительной дате) или «сегодня первый раз». Просрочка показывается спокойно: «срок был 3 дня назад», без красного и восклицаний (G-19). Сдвиг («отложить») не ломает график: следующий срок считается от фактической даты выполнения.

## 17.3 Экраны

### S17-H «Здоровье» (вход: Собака → Здоровье)
Сверху вниз:
1. **Ближайшее.** Карточка на каждый включённый план: название, срок («через 12 дней» / «сегодня» / «срок был 3 дня назад»), последний препарат, кнопка **«Сделано»**. «Сделано» открывает мини-шторку с датой «сегодня» (можно изменить) и препаратом (подставлен прошлый, можно выбрать из недавних), поле дозы (текст, необязательно), фото упаковки (необязательно); сохранение создаёт запись и пересчитывает срок за один тап «Сохранить».
2. **Быстрые отметки.** Чипы «Дала от глистов» · «Обработала от клещей» · «Прививка» · «+ Визит»: тот же путь, но без плана.
3. **Визиты.** Список последних визитов: дата, причина, клиника, итог одной строкой.
4. **Лента здоровья.** Процедуры, визиты, симптомы и вес вперемешку по времени, фильтр по типу.
5. **Итоги.** Честные факты (A-27): «Глистогонка: 4 раза за год, интервал между обработками 88–95 дней (n = 3)», «Визитов за год: 3 (плановых 2, по проблеме 1)», «Дней с последней обработки от клещей: 21».

### S17-V «Визит к ветеринару» (форма)
Все поля необязательны, кроме причины (G-18).

| Поле | Поведение |
|---|---|
| **Причина** (чипы) | **Плановый осмотр** · **Прививка** · **Из-за проблемы** · Контрольный · Другое |
| Если «Из-за проблемы» | чипы-подсказки по записанным симптомам за последние 14 дней («хромота ×3») можно привязать одним тапом; текстовое поле «что беспокоило» |
| Дата и время | по умолчанию сегодня |
| Клиника / врач | текст, запоминается и предлагается в следующий раз |
| Что сказал врач | свободный текст (диагноз записывается **словами врача**, приложение его не интерпретирует) |
| Назначения | текст; кнопка «Создать напоминание» (например, лекарство на 5 дней, повторный визит) |
| Вес на приёме | число, попадает и в журнал веса |
| Стоимость | необязательно, для годовой суммы |
| Фото и документы | заключение, анализы (хранятся локально) |
| **Следующий визит** | дата (создаёт напоминание); для планового осмотра и прививки предлагается «через 12 месяцев» |

После сохранения: тост «Визит записан», при выбранной «Прививке» обновляется план «Вакцинация».

### S17-N Напоминание (уведомление)
Локальное уведомление за настроенное число дней и в день срока (не в тихие часы, по умолчанию 22:00–07:00). Кнопки в уведомлении: **«Сделано»** (записывает процедуру с сегодняшней датой и прошлым препаратом) и **«Отложить»** (завтра / через 3 дня / через неделю). Если разрешений нет, напоминания показываются только карточкой на Today (G-22).

## 17.4 Связи с другими модулями
- **Today:** одна мягкая карточка в день по важности: просроченная процедура > вес > профиль (D-34). Кнопки «Сделано» / «Напомнить завтра» / «Скрыть».
- **Insights:** вкладка «Здоровье и активность» может показать пару рядов (вес, активность, процедуры) с метками достоверности; без причинных выводов.
- **Справка для ветеринара (PDF):** период, симптомы, процедуры с датами и препаратами, визиты, график веса.
- **Календарь (S18):** следующие сроки отмечены метками.
- **Лапки и достижения:** вовремя отмеченная профилактика даёт Лапки и достижения («Профилактика в порядке: 3 месяца подряд»); **просрочка никогда не штрафуется** и не обнуляет серию.
- **Экспорт:** все записи здоровья входят в JSON/CSV.

## 17.5 Данные (миграция 0004)
Расширение схемы `care_item` и новая таблица планов. Старый `CHECK` на `kind` сохраняется: профилактика идёт как `parasite`, подтип в `subtype`.

```sql
ALTER TABLE care_item ADD COLUMN subtype TEXT;        -- 'deworm' | 'tick_flea' | 'combined' | NULL
ALTER TABLE care_item ADD COLUMN product TEXT;        -- название препарата (текст)
ALTER TABLE care_item ADD COLUMN dose TEXT;           -- как указал врач / упаковка, текст
ALTER TABLE care_item ADD COLUMN visit_reason TEXT
  CHECK (visit_reason IN ('checkup','vaccination','problem','followup','other'));
ALTER TABLE care_item ADD COLUMN clinic TEXT;
ALTER TABLE care_item ADD COLUMN findings TEXT;       -- слова врача
ALTER TABLE care_item ADD COLUMN prescription TEXT;
ALTER TABLE care_item ADD COLUMN cost_minor INTEGER;  -- в копейках/центах, необязательно
ALTER TABLE care_item ADD COLUMN plan_id TEXT;        -- какой план выполнен

CREATE TABLE care_plan (
  id TEXT PRIMARY KEY,
  dog_id TEXT NOT NULL REFERENCES dog(id) ON DELETE CASCADE,
  template_key TEXT,                       -- 'deworm' | 'tick_flea' | 'vaccination' | 'checkup' | NULL (своё)
  kind TEXT NOT NULL,                      -- как в care_item.kind
  subtype TEXT,
  title TEXT NOT NULL,
  interval_days INTEGER,                   -- либо дни, либо месяцы
  interval_months INTEGER,
  season_from_month INTEGER CHECK (season_from_month BETWEEN 1 AND 12),
  season_to_month INTEGER CHECK (season_to_month BETWEEN 1 AND 12),
  remind_days_before TEXT NOT NULL DEFAULT '[7,0]',   -- JSON-массив
  default_product TEXT,
  enabled INTEGER NOT NULL DEFAULT 1,
  created_at TEXT NOT NULL, updated_at TEXT NOT NULL, deleted_at TEXT
);
CREATE INDEX idx_care_plan_dog ON care_plan(dog_id, enabled);
CREATE INDEX idx_care_item_dog_kind ON care_item(dog_id, kind, done_at);
```

Чистые функции (в `packages/insights`, с тестами): `nextDue(plan, lastDoneAt, now)` с сезоном и переходом через год, `dueStatus(nextDue, now)` («через N дней» / «сегодня» / «просрочено на N»), `intervalStats(doneDates)` (медиана и размах интервалов с n), напоминания `reminderMoments(plan, nextDue, quietHours)`.

## 17.6 Правила тона и безопасности
- Нет советов о препаратах, дозах и «нормальных» интервалах: интервал по умолчанию отображается как «шаблон, уточните у ветеринара или по инструкции препарата».
- Нет оценок («вы забыли»): только факты и сроки.
- Подпись на экранах: «Приложение не ставит диагнозов. При сомнениях обратитесь к ветеринару».
- Тексты шаблонов проверяет ветеринар перед релизом (R-09).

## 17.7 Критерии приёмки
1. Отметка «Дала от глистов» занимает не более двух касаний с предвыбранным препаратом.
2. Сроки пересчитываются от фактической даты выполнения; сезон клещей корректно «спит» зимой и просыпается весной (тесты на границах месяцев и на переходе через год).
3. Визит «из-за проблемы» предлагает привязать недавние симптомы; визит «прививка» обновляет план вакцинации.
4. Просрочка не окрашена тревожно и не влияет на серию и Лапки.
5. Напоминания приходят вне тихих часов, кнопки «Сделано» / «Отложить» работают без открытия приложения при живом процессе (см. D-55); без разрешений напоминания видны карточкой на Today.

# 03. Сквозной UX, навигация, онбординг, Today

## 3.1 Сквозные правила (G-xx) — действуют на всех экранах

| ID | Правило |
|---|---|
| G-01 | Цели касания ≥ 48 dp везде; на Active Walk ≥ 72 dp. Расстояние между соседними целями ≥ 8 dp. |
| G-02 | Любое удаление — мягкое: тост «Удалено · Отменить» 8 секунд; затем запись уходит в Корзину (хранится 30 дней, очистка вручную в Настройки → Данные). |
| G-03 | Автосохранение черновиков во всех формах (при сворачивании/падении черновик восстанавливается, баннер «Восстановлен черновик · Сбросить»). |
| G-04 | На Active Walk нет блокирующих модальных окон. Всё через тосты, нижние шторки и состояния кнопок. |
| G-05 | Пустое состояние: короткая фраза + одна главная кнопка + (опц.) ссылка «Показать пример на демо-данных». Никаких пустых графиков. |
| G-06 | Вибрация (haptics): лёгкая — тап по событию; «успех» — сохранение; «предупреждение» — начало удержания для деструктивного действия. Отключается в Настройках. |
| G-07 | Время 24 ч по локали; относительные даты («сегодня», «вчера», «3 дня назад»), точная дата по долгому нажатию/в деталях. |
| G-08 | Все числа и единицы выводятся через единые форматтеры (`formatDistance`, `formatDuration`, `formatPace`), учитывающие настройки единиц и локаль (склонения: «1 прогулка / 2 прогулки / 5 прогулок»). |
| G-09 | **Режим одной собаки.** Пока в приложении одна собака, интерфейс не содержит выбора собаки, чипов с именем и упоминаний «владельцев». Многособачий UI включается автоматически при добавлении второй собаки (Профиль → «Добавить собаку»). |
| G-10 | Модули выключаемы (Настройки → Модули). Выключенный модуль исчезает из навигации и с Today; данные остаются. |
| G-11 | Глобальный поиск (иконка лупы на Today и в Журнале): ищет по заметкам, местам, навыкам, типам событий, тегам; результаты сгруппированы. |
| G-12 | Доступность: поддержка системного размера шрифта до 200%, контраст AA, у каждой иконочной кнопки есть `accessibilityLabel`, смысл не передаётся только цветом (форма/иконка/подпись), уважение «уменьшить анимацию». |
| G-13 | Ни одно действие не требует сети. Сетевые операции (погода) в фоне, с тихим провалом. |
| G-14 | Все строки интерфейса — только через ключи i18n (RU/EN). Тексты для CI проверяются: нет ключей без перевода. |
| G-15 | Тосты на Active Walk появляются над панелью кнопок событий и никогда не перекрывают их. |
| G-16 | Любая запись открывается из любого места, где упоминается (событие → его прогулка, навык, место, наблюдение). |
| G-17 | «Умные дефолты»: последний выбранный контекст/место/тип запоминается; чипы сортируются по частоте использования; время суток подбирает предложение (утро/день/вечер). |
| G-18 | Формы: все поля необязательны, кроме явно отмеченных (в ТЗ — «обяз.»). Кнопка «Сохранить» активна всегда, когда данных достаточно. |
| G-19 | Тон текстов: спокойный, без восклицаний и оценок собаки («хорошая/плохая»), без стыда за пропуски. |
| G-20 | Быстрые действия по долгому нажатию на FAB (Today): «Быстрая заметка», «Туалет», «Симптом», «Фото-момент», «Лакомство». |
| G-21 | **Активный проект обучения (например, «Фризби») присутствует на всех ключевых экранах:** Today, старт и Active Walk, Summary, Training, Insights, Quests, профиль (см. `15-learning-projects-frisbee.md` §15.5). Проект можно поставить на паузу. |
| G-22 | **Мягкие карточки «актуальность данных»** на Today: не более одной в день (вес, просроченные процедуры, профиль), с кнопками «Сделать» / «Напомнить завтра» / «Скрыть». Никаких пушей по умолчанию. |
| G-23 | **Сбор данных:** максимум авто и 1 тап; ручной ввод только при необходимости (`13-data-catalog.md`). Любую категорию можно отключить. |

## 3.2 Навигация

Нижняя панель, 5 пунктов (порядок фиксирован):

| Вкладка | Содержит |
|---|---|
| **Сегодня** (Today) | сводка дня, кнопка старта, быстрые действия, цели, напоминания |
| **Прогулки** (Walks) | история (список/календарь/карта), Replay, сравнение |
| **Тренировки** (Training) | навыки, сессии, программы |
| **Инсайты** (Insights) | аналитика, паттерны, фильтры |
| **Собака** (Dog) | профиль, цели и задания (Quests), журнал поведения, места, здоровье, настройки |

Правила:
- **Журнал поведения** живёт в «Собака → Дневник» и на Today (лента), а также доступен из любой прогулки.
- При активной прогулке на панели вместо «Сегодня» появляется постоянная плашка «Идёт прогулка 00:12:34 →» над панелью; тап открывает Active Walk. Приложение при запуске с активной прогулкой сразу открывает Active Walk.
- Возврат: системная кнопка «назад» закрывает шторки, затем возвращает на предыдущий экран; на корневых вкладках — сворачивание приложения. На Active Walk «назад» ничего не завершает (только сворачивает).

## 3.3 Онбординг (S00)

Цель: профиль за ≤ 60 секунд; всё пропускаемо.

| ID | Шаг | Содержимое | Поведение |
|---|---|---|---|
| S00-1 | Приветствие | Лого, фраза «Понимай свою собаку. Одна прогулка за раз.», кнопки **Начать** и «Посмотреть на демо-собаке» | Демо загружает синтетический набор данных (флаг `is_demo`), его можно удалить одной кнопкой в Настройках. |
| S00-2 | Как зовут | Поле имени (обяз.), опц. фото (камера/галерея) | Клавиатура открыта автоматически; Enter = дальше. |
| S00-3 | О собаке | Дата рождения (или «примерно N мес/лет»), размер (мелкая/средняя/крупная/гигант), пол — всё необязательно | Если дата неизвестна, поле «Возраст» → лет + месяцев. |
| S00-4 | Что хочется улучшить | Мульти-чипы целей: Подзыв · Поводок · Выдержка · Спокойствие · Социализация · Активность · Просто вести дневник | Выбор настраивает набор быстрых меток и порядок модулей (см. §3.4); можно менять позже. |
| S00-5 | Разрешения | Объяснение «зачем» перед системным запросом: геолокация (при использовании), уведомления. Кнопки «Разрешить» / «Позже». | Если «Позже», запрос повторяется при первом старте прогулки. |
| S00-6 | Готово | Кнопка «Начать первую прогулку» и «На главный экран» | |

### Пресеты по целям (§3.4)
| Цель | Набор быстрых меток по умолчанию (панель до 9 слотов; «Ребёнок» есть в каждом пресете, кроме «Подзыв / Выдержка», где он в каталоге) | Показ на Today |
|---|---|---|
| Спокойствие / Социализация / Поводок | Собака · Человек · Животное · Успех · Сложный момент · Упражнение | Пара-карточка «Дистанция реакции» + Дневник |
| Подзыв / Выдержка | Упражнение · Успех · Сложный момент · Собака · Человек · Туалет | Навыки + последние сессии |
| Активность / Дневник | Собака · Человек · Животное · Туалет · Успех · Заметка | Статистика недели |

Пользователь меняет метки в Настройки → Быстрые метки.

## 3.4 Экран Today (S01)

Назначение: за 2 секунды понять, что сейчас важно, и запустить главное действие.

Компоновка сверху вниз (блоки можно скрывать/переставлять в Настройки → Today):

| ID | Элемент | Поведение / детали |
|---|---|---|
| S01-H | Шапка: аватар собаки, «Привет, {имя}» (опц. фраза дня), лупа | Тап по аватару → профиль. Лупа → глобальный поиск. |
| S01-W | Чип погоды: температура/ощущается, осадки, световой день («до заката 3 ч 10 мин»), качество воздуха (цвет+слово) | Данные Open-Meteo из кэша ≤ 3 ч. Без сети — чип «Погода недоступна» серым, без ошибок. Тап → мини-шторка с прогнозом на 6 ч. |
| S01-B1 | **Кнопка «Начать прогулку»** (главная, ≥ 72 dp, акцент) | Тап → Pre-walk шторка (S02). Долгое удержание → старт сразу с последними настройками (без шторки). Настройка «Быстрый старт без шторки» делает это по умолчанию. |
| S01-S | Строка статуса под кнопкой: «Последняя прогулка 4 ч назад · 32 мин» | Если прогулок ещё нет — «Здесь появится история». |
| S01-Q | Ряд быстрых действий (3 крупные плитки): **Тренировка дома** (без прогулки, `walk_id = NULL`), **Заметка**, **Туалет** | Туалет = мгновенная запись события без прогулки (тост с «Отменить»). Заметка → быстрая форма (S01-N). Тренировка → выбор навыка (последний первым) → S11. |
| S01-G | Цели недели: до 3 колец прогресса с подписью («Тренировки 2/3»), стрик-плашка («5 дней с записью»), Лапки за неделю | Тап по кольцу → экран цели. Скрывается, если модуль Quests выключен. |
| S01-Wt | **Карточка «Взвесьте собаку, пожалуйста»** (если вес не обновлялся дольше выбранного интервала, по умолчанию 14 дней; см. `16-nutrition-weight.md` §16.1) | Кнопки: «Записать вес» (шторка), «Напомнить завтра», «Скрыть». Не чаще раза в день. |
| S01-Pj | **Карточка проекта** (например, «Фризби · ступень 3»): кольцо прогресса критерия, кнопка «Сессия» | Показывается, пока проект активен (G-21). |
| S01-R | Напоминания на сегодня (максимум 3) | Свайп вправо — «Сделано», влево — «Отложить на…» (чипы: 1 ч / вечером / завтра). |
| S01-P | **Карточка дня** (одна лучшая pattern card или «давно не практиковали: Подзыв (9 дней)») | Только если хватает данных; иначе блок скрыт. Крестик — «Скрыть на неделю». |
| S01-T | Лента недавнего (последние 5 записей: прогулки, сессии, наблюдения, симптомы) | Тап → запись; «Показать всё» → Журнал/календарь. |
| S01-F | Кнопка «+» (FAB) в правом нижнем углу | Тап → шторка выбора: Прогулка (ручная запись), Тренировка, Наблюдение, Симптом, Вес, Фото. Долгое нажатие → G-20 быстрые действия. |

### S01-N Быстрая заметка (вне прогулки)
Поле текста (автофокус), чипы типа (Наблюдение · Событие · Идея · Вопрос ветеринару), кнопка камеры, привязка к времени «сейчас» (можно изменить), «Сохранить» и «Сохранить и дополнить (ABC)». Диктовка — микрофон системной клавиатуры.

### Состояния Today
- **Первый запуск:** вместо блоков S01-G/S01-T — приветственная карточка «С чего начать» (3 шага-чекбокса: прогулка, метка, цель).
- **Идёт прогулка:** S01-B1 превращается в «Вернуться к прогулке 00:12:34».
- **Есть незавершённая прогулка после падения:** баннер «Найдена незавершённая прогулка (14 мин) · Продолжить / Завершить / Удалить».
- **Вечер/ночь:** по умолчанию подсказка в S01-S «Тёмное время: до рассвета N ч» не показывается; только данные.

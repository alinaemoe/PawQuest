# 22. Что проверить на настоящих прогулках

Список того, что нельзя проверить тестами или эмулятором. Делать на Galaxy S23, по порядку; результат записывать в конец строки (✅ / ❌ + что увидела).

## A. Запись и фон (spike S1, осталось два раза)
| # | Проверка | Результат |
|---|---|---|
| A1 | Прогулка 20+ минут с выключенным экраном и телефоном в кармане: трек без дыр, расстояние похоже на реальное | |
| A2 | То же, но с паузой посередине и возобновлением | |
| A3 | Уведомление «Идёт прогулка» не пропадает; кнопки «Готово» и «Позже» (ещё не проверены) | |
| A4 | Закрыть приложение смахиванием во время прогулки: трек сохранён, прогулка восстанавливается | |
| A5 | Вход в магазин или подъезд: как ведёт себя GPS внутри, не появляются ли скачки и «улетевшие» точки | |

## B. Новые кнопки и экраны (сборка с фото)
| # | Проверка | Результат |
|---|---|---|
| B1 | Кнопка «Сложный момент»: шрифт не уехал, влезает в кнопку | |
| B2 | Удержание «Завершить»: заливка идёт слева направо, отпустить раньше конца отменяет, коротким тапом приходит подсказка | |
| B3 | Долгое нажатие на кнопку события открывает карточку деталей; после «Готово» детали сохранены | |
| B4 | Собака → «Быстрые метки»: добавить свою метку, скрыть, вернуть, поменять порядок; панель на прогулке соответствует | |
| B5 | Камера на прогулке: разрешение, снимок, миниатюры в итогах, просмотр, удаление с отменой | |
| B6 | Фото сделано сразу после события прикрепилось к событию (в пределах 90 секунд) | |
| B7 | Приложение не вылетает при повороте экрана и при возврате из камеры | |

## C. Погода и места
| # | Проверка | Результат |
|---|---|---|
| C1 | Погода на старте совпадает с тем, что за окном (мокро / сухо, ветер); расстояние до узла сетки показано | |
| C2 | После дождя: «мокро» и «давно ли дождь» похожи на правду | |
| C3 | Парк 900-летия Минска: качество контура из OpenFreeMap (spike S8), нужен ли контур вместо радиуса | |
| C4 | Предложение «Вы часто останавливаетесь здесь»: после 3 прогулок рядом с одним местом | |
| C5 | Порог «база»: заход в дом или к маме на 15+ минут: предлагает ли приложение завершить прогулку | |
| C6 | Длинные заходы к маме (~2 часа): подсказка «Завершить?» вовремя, без раздражения | |
| C7 | Заход в магазин: прогулка не прерывается и не считается остановкой собаки | |

## D. Ощущения (субъективно)
- Достаточно ли быстро нажимать кнопки событий на ходу, одной рукой, в перчатках.
- Не раздражают ли тосты, вибрация, подсказки.
- Читается ли экран на солнце в обеих темах.
- Расход батареи за прогулку (проценты на старте и в конце, длительность).

## Что делать с результатами
Каждая ❌ превращается в запись в `02-decisions.md` или задачу в `12-roadmap.md`; пороги из D-60 и D-62 подстраиваются по C1–C7.

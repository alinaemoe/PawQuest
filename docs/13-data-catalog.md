# 13. Каталог данных: что собираем везде и как

Принцип (D-32): **собирать максимум данных, но почти всё автоматически или одним тапом**. Ручной ввод — только там, где иначе не получить. Всё хранится локально; всё необязательное можно выключить в Настройки → Данные → «Что собирать».

Три уровня сбора:
- **Авто** — приложение пишет само, без участия пользователя.
- **1 тап** — одна кнопка/чип.
- **По желанию** — поле, которое можно пропустить.

## 13.1 Прогулка

| Данные | Уровень | Откуда | Зачем (инсайты) |
|---|---|---|---|
| Трек (точка, время, точность, скорость, высота) | Авто | GPS | маршрут, Replay, скорость, зоны скорости, набор высоты |
| Время общее / в движении / пауз / стоянок | Авто | расчёт | активность, сравнение с обычным |
| Скорость: текущая, средняя, профиль по времени, **время в зонах скорости** | Авто | расчёт (A-25) | «сколько минут на какой скорости», начало быстрее/конец медленнее |
| Остановки (число, длительность, места остановок) | Авто | расчёт | обнюхивание/ожидание, кластеры мест |
| Число шагов владельца, каденс | Авто (если датчик) | шагомер | запасной показатель без GPS |
| Высота и набор | Авто | GPS | рельеф маршрута |
| Погода: температура, ощущается, осадки, ветер, влажность, УФ, давление | Авто (онлайн) | Open-Meteo | контекст для закономерностей |
| Качество воздуха и **пыльца** (если доступно) | Авто (онлайн) | Open-Meteo | контекст |
| Световой день: рассвет, закат, «до заката», тёмное/светлое | Авто | расчёт по координатам и дате | время суток как фактор |
| Фаза Луны | Авто | расчёт | (опционально, любопытство; по умолчанию выключено) |
| Сезон, день недели, праздничные дни | Авто | расчёт | ритм |
| Время с прошлой прогулки, число прогулок за день | Авто | расчёт | нагрузка дня |
| Тип поверхности (трава/асфальт/снег) | 1 тап | чип в Summary | контекст |
| Состояние собаки, отвлечение | 1 тап | Summary | оценка прогулки |
| Заряд батареи на старте/финише | Авто | ОС | диагностика расхода |
| Источник GPS и точность | Авто | ОС | достоверность трека |
| Фото | 1 тап | камера | альбом прогулки, привязка к времени/месту |
| Заметка | По желанию | клавиатура/диктовка | |

## 13.2 События и поведение
Время, координата, тип, дистанция, реакция, отвлечение, восстановление (таймер), что делала я, итог, интерпретация, фото — см. S04. Авто-контекст к каждому событию: скорость в этот момент, время с начала прогулки, погода на момент, число событий за последние 10 мин (для нагрузки).

## 13.3 Тренировки и проекты
Навык, ступень, контекст, отвлечение, награда (**что и сколько съедено, из библиотеки лакомств**), число и результат попыток, длительность, место и погода (авто), порядковый номер сессии, интервал с прошлой сессией (авто). Для проекта «Фризби»: дистанция/высота броска, тип диска, поверхность, ветер (авто), вовлечённость 1–5 (см. `15-learning-projects-frisbee.md`).

## 13.4 Здоровье и уход
Вес (дата, значение, условия: утром/до еды), симптомы, процедуры, визиты, лекарства (текст), температура тела (по желанию, число), аппетит (3 уровня, 1 тап в конце дня), стул (3 уровня, по желанию), сон (по желанию, часы). Всё нейтральные записи без оценки.

## 13.5 Питание и вкусняшки
Каждое лакомство/погрызушка: что, сколько (граммы или штуки), когда, контекст (на прогулке / на тренировке / дома), оценка ккал (приблизительно, из справочника, см. `16-nutrition-weight.md`). Основной корм: «обычный рацион сегодня» одним тапом (по желанию, с граммами).

## 13.6 Пассивные «метаданные»
Время открытия приложения, использование модулей (локально, §7.7), версия данных, ошибки (локальный лог).

## 13.7 Правила
1. Нет сбора ради сбора: каждое поле имеет отображаемое применение в инсайтах (колонка «Зачем»).
2. Всё, что собирается онлайн (погода, пыльца), опционально и без личных данных (грубые координаты, округление до 0,05°).
3. Пользователь видит, что собрано: экран «Что известно об этой прогулке» (раскрывающийся список в Walk Details).
4. Любую категорию можно отключить без потери остальных функций.
5. Экспорт включает все собранные поля (CSV/JSON).
